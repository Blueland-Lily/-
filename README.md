# 🌸 女性创业者内在充电站 MVP

## 快速上线指南

### 方法一：直接打开（最快）
1. 双击 `index.html` 文件
2. 直接在浏览器中使用
3. ✅ **立即可用，无需服务器**

### 方法二：本地服务器（推荐）
```bash
# Python 方式（如果有 Python）
python -m http.server 8000

# Node.js 方式（如果有 Node.js）
npx http-server

# PHP 方式（如果有 PHP）
php -S localhost:8000
```

然后访问：http://localhost:8000

### 方法三：在线部署（明天就能公开访问）
1. 将 `index.html` 上传到任何静态网站托管：
   - **Vercel**（推荐）：vercel.com
   - **Netlify**：netlify.com
   - **GitHub Pages**：创建仓库，上传文件，开启 Pages
2. 获得公开链接
3. 分享给第一批测试用户

## 技术栈

- **纯 HTML + CSS + JavaScript**
- **LocalStorage** 数据持久化（浏览器本地存储）
- **零依赖**：不需要 Node.js、数据库、服务器

---

## 数据说明

- 用户数据保存在浏览器 LocalStorage
- 数据不会丢失（清除浏览器数据除外）
- **限制**：仅限单设备访问

**后期升级路径**：
